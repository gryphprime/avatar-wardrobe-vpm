## Findings fixed

| Finding | Impact and correction |
| --- | --- |
| P2: Retry left sibling previews unavailable | Retrying the selected image recovered its pixels while the filmstrip and catalog could retain a failure. Visible consumers now adopt the recovered shared cache without another render request. |
| P2: Retry lost selected-image styling | Retry discarded the detail binding options. It now preserves the large-image class and identity. |
| P2: Explicit retry could persist into upgrades | A binding retained its one-time retry flag for later automatic cache upgrades. Stored binding options now clear retry so upgrades cannot repeat the mutation. |
| P1: Linux package validation failed after tests | Python tests generated bytecode inside the indexer folder. Preflight now excludes the same generated inputs as packaging while still rejecting missing Unity metadata and duplicate GUIDs. |
| P1: New Unity fixtures lacked their safety marker | The fixture builder omitted the marker required by current scene-mutating regression tests. Newly created disposable fixtures now receive the exact marker; existing directories are still rejected. |
