Avatar Wardrobe

VPM repository for authorized users of Avatar Wardrobe.

Open in VCC / ALCOM

Your browser may ask permission to open the app. If nothing happens, use the manual steps below.

1. Add the repository

Use Open in VCC / ALCOM above and confirm the repository in the app, or add it manually:

  1. Open ALCOM and go to Repositories → Add Repository.
  2. Paste this repository URL and confirm the repository.
https://gryphprime.github.io/avatar-wardrobe-vpm/index.json

Why doesn't the app link open?

The link uses the vcc: URL scheme. An installed application must register that scheme, and the browser must allow opening it.

If your ALCOM settings offer Use ALCOM for vcc: URL Scheme, enable it and click Register URL Scheme Handler Now. These controls are platform-dependent; if they are absent, use the manual steps above.

2. Install Avatar Wardrobe

  1. Close the target project in Unity.
  2. In ALCOM, open your project's Manage Packages page.
  3. Refresh the package list, search for Avatar Wardrobe, and install it.
  4. Review and apply the package changes.

Regular releases appear without enabling prerelease packages.

VPM resolves the required VRChat SDK Avatars and Modular Avatar packages. If Modular Avatar cannot be found, add its repository using the Modular Avatar installation page.

An existing Assets/OutfitToggleGenerator installation is migrated automatically.

3. Open Avatar Wardrobe in Unity

Open the project in Unity. After compilation finishes, choose Tools → Avatar Wardrobe.

The VPM package still needs a fresh installation smoke test. Start with a separate test project before installing it in your main avatar project.

Update Avatar Wardrobe

Close the project in Unity. In ALCOM or VCC, open the project’s Manage Packages page, refresh the list, and update Avatar Wardrobe to the latest version. Apply the changes, then reopen Unity and wait for compilation.
